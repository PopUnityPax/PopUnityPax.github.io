## 🌱 Ways to Contribute

- **Code** – Fix bugs, build features, or improve performance
- **Design** – Improve UI/UX, create assets, or write Figma specs
- **Documentation** – Improve READMEs, guides, or in-app copy
- **Translation** – Help make PopUnityPax accessible in more languages
- **Community** – Answer questions, triage issues, or help moderate discussions
- **Ideas** – Open an issue to propose new features or improvements

---

## 🚀 Getting Started

1. **Fork** this repository and clone your fork locally.
2. Create a new branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes, keeping commits small and focused.
4. Test your changes thoroughly.
5. Push your branch and open a **Pull Request** against `main`.

---

## 📥 Submitting a Pull Request

Please make sure your PR:

- Has a clear, descriptive title (e.g. `Add Pax Room dark mode support`)
- Includes a summary of *what* you changed and *why*
- References any related issues (e.g. `Closes #42`)
- Follows the existing code style and conventions
- Does not break existing functionality

We review PRs regularly and will provide feedback as quickly as possible. Thank you for your patience!

---

## 🔄 Updating Your Pull Request

A maintainer may ask you to update your PR before it's merged — this is normal and part of our collaborative review process. To update your PR:

1. Make the requested changes on your local branch.
2. Commit and push to the same branch — the PR updates automatically.
3. Leave a comment to let us know the changes are ready for re-review.

---

## 🐛 Reporting Bugs & Suggesting Features

- **Bugs:** Open an issue with the label `bug`. Include steps to reproduce, expected behaviour, and actual behaviour.
- **Feature requests:** Open an issue with the label `enhancement`. Describe the problem it solves and your proposed solution.

---

## 📜 Code of Conduct

PopUnityPax is a community built on **empathy, respect, and unity**. We expect all contributors to:

- Be kind and constructive in all interactions
- Respect differing viewpoints and experiences
- Give and receive feedback graciously
- Focus on what is best for the community

Harassment, discrimination, or harmful behaviour of any kind will not be tolerated and may result in removal from the project.

Questions or concerns? Reach out at [@TAYTOKTEATALK](https://x.com/TAYTOKTEATALK) or via the contact details in the [README](README.md).
